Características Principales

Anti AFK Farm

Previene que los jugadores farmeen recursos mientras están AFK.

  • Detección de inactividad
  • Verificación de movimientos repetitivos
  • Alertas automáticas para admins
  • Sistema de expulsión configurable

Anti Bunny Jump

Elimina el salto continuo para mantener el realismo en el roleplay.

  • Límite de saltos consecutivos
  • Cooldown entre saltos
  • Penalización por abuso
  • Sistema de fatiga realista

Anti Armor Stacking

Previene el abuso de acumulación de armaduras.

  • Límite de armadura máxima
  • Detección de uso excesivo
  • Registro de eventos
  • Notificaciones al staff

Anti Super Punch

Normaliza el daño de los golpes para evitar one-hits injustos.

  • Daño balanceado de puñetazos
  • Prevención de modificadores
  • Sistema de combate justo
  • Detección de anomalías

Anti Fall Damage

Gestiona el daño por caída de forma realista evitando abusos.

  • Daño realista por caída
  • Prevención de god mode
  • Configuración de umbrales
  • Logs de eventos sospechosos

Anti Punctured Wheels

Previene el abuso de ruedas pinchadas para ventajas injustas.

  • Control de estado de neumáticos
  • Prevención de modificaciones
  • Reparación automática en casos de abuso
  • Sistema de advertencias

Auto /me Cacheo

Sistema automático de roleplay para cacheos y registro de personas.

  • Mensajes automáticos de /me
  • Sistema de proximidad
  • Textos personalizables
  • Integración con inventario

Sistema Modular

Cada módulo puede activarse o desactivarse independientemente.

  • Configuración individual por módulo
  • Fácil personalización
  • Sin dependencias entre módulos
  • Actualizaciones modulares
Realismo y Balance: Todos los módulos están diseñados para mantener un equilibrio entre realismo, jugabilidad y prevención de abusos, mejorando la experiencia de roleplay en tu servidor.

Guía de Instalación

1

Descargar y Extraer

Descarga el script y colócalo en tu carpeta de recursos

# Estructura recomendada
resources/[ps]/ps_antiPG/
2

Configuración Inicial

Edita el archivo config.lua según tus necesidades

Config = {
    -- Activar/Desactivar módulos
    AntiAFKFarm = true,
    AntiBunnyJump = true,
    AntiArmorStacking = true,
    AntiSuperPunch = true,
    AntiFallDamage = true,
    AntiPuncturedWheels = true,
    AutoMeCacheo = true,
    
    -- Configuraciones generales
    Debug = false,
    Notifications = true,
}
3

Añadir al Server.cfg

Asegura el recurso en tu servidor

# Añadir al server.cfg
ensure ps_antiPG
4

Configurar Permisos

Define los grupos de administradores que recibirán alertas

Config.AdminGroups = {
    'admin',
    'superadmin',
    'moderador'
}
5

Reiniciar y Verificar

Reinicia el servidor y comprueba que todo funcione correctamente

# Reiniciar el recurso
restart ps_antiPG

# Verificar estado
status
Instalación Completada! El sistema anti-PG estará activo inmediatamente protegiendo tu servidor.

Módulos Detallados

Anti AFK Farm

Previene que jugadores AFK obtengan recursos de forma injusta.

Config.AntiAFKFarm = {
    enabled = true,
    checkInterval = 60000,      -- 1 minuto
    maxInactiveTime = 300000,   -- 5 minutos
    kickOnDetection = true,
    notifyAdmins = true
}

Características:

  • Detección inteligente de movimientos
  • Verificación de acciones repetitivas
  • Sistema de advertencias progresivo

Anti Bunny Jump

Elimina el salto continuo para mantener el realismo.

Config.AntiBunnyJump = {
    enabled = true,
    maxConsecutiveJumps = 3,
    jumpCooldown = 2000,        -- 2 segundos
    applyStaminaPenalty = true
}

Características:

  • Límite de saltos consecutivos
  • Sistema de fatiga realista
  • Cooldown configurable

Anti Armor Stacking

Previene la acumulación abusiva de armadura.

Config.AntiArmorStacking = {
    enabled = true,
    maxArmor = 100,
    checkInterval = 5000,       -- 5 segundos
    removeExcess = true,
    logEvents = true
}

Características:

  • Límite máximo de armadura
  • Detección de modificaciones
  • Registro automático de abusos

Anti Super Punch

Normaliza el daño de combate cuerpo a cuerpo.

Config.AntiSuperPunch = {
    enabled = true,
    normalDamage = 10,
    maxDamagePerHit = 15,
    detectModifiers = true
}

Características:

  • Daño balanceado
  • Detección de modificadores
  • Prevención de one-hit kills

Anti Fall Damage

Gestiona el daño por caída de forma realista.

Config.AntiFallDamage = {
    enabled = true,
    realisticDamage = true,
    minHeightForDamage = 5.0,   -- metros
    preventGodMode = true
}

Características:

  • Cálculo realista de daño
  • Prevención de god mode
  • Umbrales configurables

Anti Punctured Wheels

Previene abusos relacionados con neumáticos.

Config.AntiPuncturedWheels = {
    enabled = true,
    autoRepair = true,
    checkInterval = 10000,      -- 10 segundos
    warnPlayers = true
}

Características:

  • Control de estado de ruedas
  • Reparación automática anti-abuse
  • Sistema de advertencias

Auto /me Cacheo

Automatiza mensajes de roleplay para cacheos.

Config.AutoMeCacheo = {
    enabled = true,
    proximityRadius = 2.0,      -- metros
    customMessage = "cachea a la persona",
    showToNearby = true
}

Características:

  • Mensajes automáticos de /me
  • Detección de proximidad
  • Textos personalizables

Config.AutoActions = {

    violationsBeforeKick = 5,
    banOnPersistence = true,
    banDuration = 86400  -- 24 horas
}

Solución de Problemas

Los módulos no funcionan

  • Verifica que cada módulo esté activado en config.lua
  • Comprueba que no hay conflictos con otros scripts
  • Revisa la consola del servidor por errores
  • Asegúrate de que el recurso está iniciado

No recibo notificaciones

  • Verifica que eres parte de Config.AdminGroups
  • Comprueba que las notificaciones están activadas
  • Revisa el tipo de sistema de notificaciones
  • Asegúrate de tener los permisos correctos

Falsos positivos

  • Ajusta los umbrales en la configuración
  • Añade jugadores a la whitelist si es necesario
  • Revisa los intervalos de verificación
  • Activa el modo debug para más información
Modo Debug: Activa Config.Debug = true para obtener información detallada en consola y facilitar la resolución de problemas.
