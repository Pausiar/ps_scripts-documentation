⚙️ Instalación

1. Descarga el script

Descarga el script desde [enlace/ubicación]

2. Extrae los archivos

Extrae el contenido en tu carpeta de recursos:

server-data/resources/[tu-carpeta]/ps_[nombre_script]/

3. Importa la base de datos

Importa el archivo SQL incluido en tu base de datos:

ps_[nombre_script].sql

4. Configura el archivo

Edita el archivo config.lua según tus necesidades (ver sección de configuración).

5. Añade al server.cfg

ensure ps_[nombre_script]

6. Reinicia el servidor

Reinicia tu servidor y el script estará listo para usar.

🔧 Configuración

El archivo config.lua contiene todas las opciones configurables:

Configuración General

Config = {}

-- Configuración general
Config.Framework = 'esx' -- 'esx', 'qbcore', 'standalone'
Config.Locale = 'es' -- Idioma: 'es', 'en'

-- Ejemplo de configuración específica
Config.EnableFeature = true
Config.MaxDistance = 10.0
💡 Consejo: Ajusta las distancias y tiempos según las necesidades de tu servidor.
