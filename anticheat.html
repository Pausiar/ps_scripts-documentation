Advanced AntiCheat System para FiveM - PS Anticheat

Sistema anti-cheat avanzado para servidores FiveM con detección de menús en pantalla, verificación de eventos seguros y detección de props anómalas. Incluye sistema completo de base de datos.

Características Principales

Detección de Menús en Pantalla (Anti On-Screen Menu)

  • Toma capturas de pantalla periódicamente y las analiza
  • Detecta menús tipo lua menu automáticamente
  • Sanción automática al detectar menús de trampas

Safe Events Verification System

  • Verifica eventos "seguros" para prevenir exploits
  • Bloquea eventos maliciosos como spawn de dinero
  • Lista negra y blanca de eventos personalizable
  • Detección de cantidades sospechosas

Detección de Props/Entidades Anómalas (AI Props Detection)

  • Detecta comportamiento inusual en spawn de props
  • Control de límites por jugador
  • Blacklist de modelos prohibidos
  • Previene spam de objetos que afecten el rendimiento

NUEVO: Sistema Completo de Base de Datos

  • Almacenamiento persistente de violaciones y bans
  • Sistema de bans con duración temporal y permanente
  • Whitelist con razones y administradores responsables
  • Estadísticas avanzadas y reportes detallados
  • Trust Score automático para jugadores
  • Logs completos del sistema
  • Capturas de pantalla con metadata

Instalación

Paso 1: Preparar la Base de Datos

IMPORTANTE: Configura primero la base de datos antes de instalar el resource.

Opción A: MySQL/MariaDB (Recomendado)

1. Ejecuta el archivo anticheat_install.sql en tu base de datos:

mysql -u tu_usuario -p tu_base_de_datos < anticheat_install.sql

2. Instala uno de estos resources de MySQL:

  • mysql-async (más común)
  • oxmysql (más moderno)
  • ghmattimysql (legacy)
# En tu server.cfg
ensure mysql-async  # O el que prefieras

Opción B: Sin Base de Datos

Si no quieres usar base de datos, configura en config.lua:

Config.General.UseDatabase = false

Paso 2: Instalar el Resource

  1. Descarga todos los archivos del sistema
  2. Crea carpeta ps_anticheat en resources/[anticheat]/
  3. Descomprime los archivos a la carpeta

Paso 3: Configurar el Sistema

Edita config.lua:

-- Habilitar base de datos
Config.General.UseDatabase = true
Config.General.DatabaseType = "mysql"  -- mysql o sqlite

-- Configurar tu servidor
Config.General.ServerName = "Mi Servidor RP"

-- Configurar capturas
Config.Screenshot.Enabled = true
Config.Screenshot.WebhookURL = "tu_webhook_discord"  -- Opcional

-- Configurar detecciones
Config.SafeEvents.Enabled = true
Config.PropsDetection.Enabled = true

Paso 4: Permisos y Server.cfg

Añade a tu server.cfg:

# Dependencias
ensure mysql-async          # O tu system de MySQL
ensure screenshot-basic     # Para capturas
ensure advanced-anticheat

# Permisos básicos
add_ace group.admin anticheat.admin allow
add_ace group.admin anticheat.notify allow
add_ace group.mod anticheat.view allow

# Exenciones para staff (opcional)
add_ace identifier.steam:110000100000000 anticheat.exempt allow

Paso 5: Primera Ejecución

  1. Reinicia el servidor
  2. Usa /anticheat:status para verificar funcionamiento
  3. Usa /ac para abrir el panel de admin
  4. Configura según tus necesidades

Configuración Avanzada

Sistema de Sanciones Progresivas

Config.Sanctions.Progressive = {
    Enabled = true,
    Rules = {
        Critical = {  -- ONSCREEN_MENU, AIMBOT, etc.
            Actions = {"SCREENSHOT", "TEMP_BAN", "BAN"}
        },
        Severe = {    -- BLACKLISTED_PROP, INFINITE_AMMO, etc.
            Actions = {"WARNING", "KICK", "TEMP_BAN", "BAN"}
        },
        Minor = {     -- SPEED_ANOMALY, TOO_MANY_PROPS, etc.
            Actions = {"WARNING", "WARNING", "KICK", "TEMP_BAN"}
        }
    }
}

Sistema de Capturas de Pantalla

Config.Screenshot = {
    Enabled = true,
    Interval = 30000,        -- 30 segundos entre capturas
    Quality = 0.8,           -- Calidad de imagen (0.1-1.0)
    AIAnalysis = true,       -- Análisis automático
    WebhookURL = "tu_webhook" -- Discord webhook (opcional)
}

Eventos Seguros

Config.SafeEvents = {

        "esx:addMoney",

Consultas Útiles

Ver Top Violadores de la Semana

SELECT player_name, COUNT(*) as violations 
FROM anticheat_violations 
WHERE timestamp >= DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY player_identifier, player_name 
ORDER BY violations DESC LIMIT 10;

Ver Jugadores con Bajo Trust Score

SELECT player_name, total_violations, trust_score, last_violation
FROM anticheat_players 
WHERE trust_score < 20 AND total_violations > 0 AND NOT is_whitelisted
ORDER BY trust_score ASC;

Solución de Problemas

Error: "Base de datos no disponible"

Solución: Verifica que mysql-async/oxmysql esté funcionando y las tablas creadas.

Error: "Tabla no existe"

Solución: Ejecuta el script anticheat_install.sql completo.

Panel web no funciona

Solución: Verifica permisos anticheat.admin y conexión a BD.

Rendimiento con BD

Solución: Ajusta Config.Performance.Intervals para reducir consultas.

Monitoreo de Rendimiento

Con base de datos habilitada, monitorea:

  • Consultas/segundo: No debería exceder 10-20
  • Latencia BD: Mantener bajo 50ms
  • Tamaño tablas: Limpieza automática cada 24h
  • Memoria: ~50-100MB adicionales con BD

Seguridad de la Base de Datos

  • Acceso restrictivo: Solo el resource debe acceder a las tablas
  • Validación: Todos los inputs son sanitizados
  • Logs auditables: Todas las acciones se registran
  • Backup regular: Respalda las tablas del AntiCheat
  • Cleanup: Datos antiguos se eliminan automáticamente

Instalación Rápida con Base de Datos

# 1. Crear base de datos
mysql -u root -p -e "CREATE DATABASE anticheat_db;"

# 2. Instalar tablas
mysql -u root -p anticheat_db < anticheat_install.sql

# 3. Configurar server.cfg
echo "ensure mysql-async" >> server.cfg
echo "ensure advanced-anticheat" >> server.cfg

# 4. Configurar permisos
echo "add_ace group.admin anticheat.admin allow" >> server.cfg

# 5. Reiniciar servidor y usar /ac
¡Tu servidor ahora tiene el sistema AntiCheat más avanzado con base de datos completa!

Sistema de Sanciones

Sanciones Progresivas

  1. Primera violación: Advertencia
  2. Segunda violación: Kick
  3. Tercera violación: Ban temporal
  4. Cuarta violación: Ban permanente

Tipos de Violaciones

  • Críticas: ONSCREEN_MENU, AIMBOT, GOD_MODE
  • Graves: BLACKLISTED_PROP, INFINITE_AMMO
  • Leves: SPEED_ANOMALY, TOO_MANY_PROPS

Tipos de Detección

1. Menús en Pantalla

  • Patrones de texto sospechosos
  • Análisis de capturas automático
  • Detección de overlays de menús

2. Eventos Maliciosos

  • Interceptación de eventos del servidor
  • Verificación de parámetros
  • Bloqueo de exploits conocidos

3. Props Anómalos

  • Límites de spawning
  • Modelos prohibidos
  • Detección de spam

4. Modificaciones del Jugador

  • God Mode
  • Armadura infinita
  • Velocidad anómala
  • Munición infinita
  • Teletransporte

Optimización de Rendimiento

Configuración Recomendada

Config.Performance = {
    MaxCPUUsage = 2.0,     -- ms por frame
    DynamicLimits = true,   -- Ajustar según jugadores
    Intervals = {
        PlayerScan = 2000,   -- Menos frecuente con muchos jugadores
        EntityScan = 3000
    }
}

Servidores con 64+ Jugadores

  • Aumentar intervalos de escaneo
  • Activar límites dinámicos
  • Considerar deshabilitar algunas detecciones menos críticas
