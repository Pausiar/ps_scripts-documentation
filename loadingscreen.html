Guía de Instalación

1

Descargar y Extraer

Descarga el recurso y extráelo en tu carpeta de recursos

# Extraer en la carpeta de recursos
resources/[loading]/ps_loadingscreen/
2

Configurar Server.cfg

Añade el loading screen al inicio de tu server.cfg

# Debe ir antes de otros recursos
loadscreen "ps_loadingscreen/index.html"
ensure ps_loadingscreen
3

Personalizar Recursos

Añade tus propias imágenes y música a las carpetas correspondientes

# Estructura de carpetas
/images/backgrounds/    -> Fondos de pantalla
/images/characters/     -> Imágenes de personajes
/music/                 -> Archivos de música
4

Configurar Opciones

Edita el archivo config.lua para personalizar el comportamiento

Config = {
    MusicVolume = 0.3,          -- Volumen de música (0.0 - 1.0)
    ShowCharacters = true,       -- Mostrar galería de personajes
    BackgroundRotation = true,   -- Rotación automática de fondos
    RotationInterval = 10000,    -- Intervalo en milisegundos
}
5

Reiniciar y Probar

Reinicia tu servidor y prueba conectándote

# En la consola del servidor
restart ps_loadingscreen

# O reinicia el servidor completo
restart

Configuración Avanzada

Personalización de Música

Configura la música de fondo:

// En js/index.js
const musicFiles = [
    'music/track1.mp3',
    'music/track2.mp3',
    'music/track3.mp3'
];

Fondos de Pantalla

Añade tus propias imágenes de fondo:

// Coloca imágenes en:
images/backgrounds/bg1.jpg
images/backgrounds/bg2.jpg
images/backgrounds/bg3.jpg

// Formatos soportados: JPG, PNG, WEBP

Sistema de Personajes

Configura los personajes del servidor:

// En js/index.js
const characters = [
    {
        name: "Nombre",
        role: "Rol",
        image: "characters/char1.png"
    }
];

Textos e Información

Personaliza los textos mostrados:

// En index.html
<div class="server-info">
    <h1>Tu Servidor RP</h1>
    <p>Bienvenido a la mejor experiencia de roleplay</p>

Consejos y Mejores Prácticas

Optimización de Imágenes

  • Usa formatos WEBP para mejor compresión
  • Resolución recomendada: 1920x1080
  • Mantén el tamaño de archivo bajo 500KB
  • Usa herramientas de compresión

Música

  • Formatos recomendados: MP3, OGG
  • Bitrate: 128-192 kbps
  • Asegúrate de tener derechos de uso
  • Volumen normalizado

Rendimiento

  • No uses demasiadas imágenes pesadas
  • Limita el número de fondos a 3-5
  • Optimiza el código JavaScript
  • Prueba en diferentes navegadores

Diseño

  • Mantén la coherencia con tu marca
  • Usa colores que combinen bien
  • Asegura buena legibilidad del texto
  • Prueba en diferentes resoluciones

Solución de Problemas

La pantalla de carga no aparece

  • Verifica que loadscreen esté antes de ensure
  • Comprueba la ruta del index.html
  • Revisa la consola del servidor por errores
  • Asegúrate de que fxmanifest.lua está correcto

La música no se reproduce

  • Verifica que los archivos estén en /music/
  • Comprueba el formato del archivo
  • Revisa la configuración de volumen
  • Algunos navegadores bloquean autoplay

Las imágenes no cargan

  • Verifica las rutas en el código
  • Comprueba los formatos soportados
  • Revisa los permisos de archivos
  • Asegúrate de que las imágenes existen
