## ➕ Añadir Nueva Documentación

¿Quieres documentar un nuevo script? ¡Es fácil!

Lee la guía completa: [**COMO_AGREGAR_DOCUMENTACION.md**](./COMO_AGREGAR_DOCUMENTACION.md)

### Pasos Rápidos:

1. Copia `TEMPLATE.html` y renómbralo (ej: `mi_script.html`)
2. Completa la información del script
3. Añade una tarjeta en `index.html`
4. ¡Listo! Tu documentación está agregada
