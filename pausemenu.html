Guía de Instalación

1

Descargar y Extraer

Descarga el script y colócalo en tu carpeta de recursos

# Estructura recomendada
resources/[menu]/ps_pausemenu/
2

Configurar el Script

Edita el archivo ps-config.lua para personalizar el menú

Config = {
    Framework = 'esx',              -- 'esx' o 'qbcore'
    ServerName = 'Tu Servidor RP',
    ServerLogo = 'URL_DEL_LOGO',
    DiscordLink = 'discord.gg/tu-servidor',
    WebsiteLink = 'tu-website.com'
}
3

Añadir al Server.cfg

Asegura el recurso en tu configuración del servidor

# Añadir al server.cfg
ensure ps_pausemenu
4

Personalizar la UI

Modifica los estilos CSS para que coincidan con tu servidor

/* En ps-design.css */
:root {
    --primary-color: #8b5cf6;
    --secondary-color: #ec4899;
    --background-dark: #0f172a;
}
5

Reiniciar y Probar

Reinicia el servidor y presiona ESC para abrir el menú

# Reiniciar el recurso
restart ps_pausemenu
¡Instalación Completada! Los jugadores ahora tendrán acceso al nuevo menú de pausa presionando la tecla ESC.

Personalización de la Interfaz

Guía de Personalización Visual

1

Cambiar Logo del Servidor

Personaliza el logo que aparece en el menú

  • Usa formato PNG con fondo transparente
  • Resolución recomendada: 512x512 píxeles
  • Sube a imgur u otro hosting de imágenes
  • Actualiza la URL en ps-config.lua
2

Personalizar Esquema de Colores

Adapta los colores a la identidad de tu servidor

  • Edita las variables CSS en ps-design.css
  • Usa colores que contrasten bien
  • Mantén la legibilidad del texto
  • Prueba en diferentes resoluciones
3

Añadir Iconos Personalizados

Cambia los iconos de las diferentes secciones

  • Usa Font Awesome o iconos personalizados
  • Modifica ps-index.html
  • Mantén el tamaño consistente
  • Asegura compatibilidad con todos los navegadores
4

Modificar Diseño y Layout

Ajusta la disposición de elementos según tus preferencias

  • Edita el HTML en ps-index.html
  • Ajusta el CSS en ps-design.css
  • Modifica el JavaScript en ps-app.js si es necesario
  • Prueba todos los cambios antes de publicar

Solución de Problemas

El menú no se abre

  • Verifica que el recurso esté iniciado
  • Comprueba la consola F8 por errores
  • Asegúrate de que NUI esté habilitado
  • Verifica la tecla configurada (ESC por defecto)

La información no se actualiza

  • Verifica la conexión con el framework
  • Comprueba que Config.Framework esté correcto
  • Revisa los eventos del servidor
  • Asegúrate de que esx_status esté funcionando

Problemas visuales o de diseño

  • Limpia la caché del navegador NUI
  • Verifica que los archivos CSS no estén corruptos
  • Comprueba la resolución de pantalla
  • Prueba con diferentes escalas de UI
Nota: Si experimentas problemas persistentes, prueba con una instalación limpia del recurso y verifica que no haya conflictos con otros menús o HUDs.
