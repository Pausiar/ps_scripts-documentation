PS Anti-Tanqueo para FiveM

Script diseñado para mejorar la experiencia de rol en servidores FiveM, evitando el tanqueo y aportando realismo cuando un jugador recibe un headshot.

Descargar de GitHub Guía de Instalación

✨ Características Principales

🔫 Sistema de Headshots

Detección precisa de headshots con efectos realistas

⚰️ Muerte Directa

Opción configurable para muerte instantánea por headshot

🤕 Estado de Inconsciencia

Desmayo temporal de 4 segundos con efectos visuales

🍺 Efecto Borracho

Simulación de desorientación tras el impacto

⚙️ Altamente Configurable

Ajusta duración, efectos y comportamientos

🚀 Optimizado

Código ligero sin afectar el rendimiento del servidor

💡 Realismo Mejorado: Este script añade una capa extra de realismo al combate, haciendo que los headshots tengan consecuencias más significativas y reduciendo el "tanqueo" en situaciones de roleplay.

📦 Instalación

Paso 1: Descarga

Descarga el recurso desde el repositorio de GitHub y colócalo en tu carpeta resources/.

Paso 2: Configuración del Servidor

Añade la siguiente línea a tu archivo server.cfg:

ensure ps_antitank

Paso 3: Reinicio

Reinicia tu servidor y el script estará funcionando automáticamente.

✅ ¡Instalación Completada! El script comenzará a funcionar inmediatamente sin necesidad de configuración adicional.

⚙️ Configuración

En el archivo de configuración puedes ajustar los siguientes parámetros:

Opciones Principales

  • Duración del estado de inconsciencia: Configura cuánto tiempo permanece inconsciente el jugador
  • Efectos visuales y sonoros: Activa/desactiva el efecto borracho y otras animaciones
  • Modo de muerte: Elige entre muerte instantánea o desmayo temporal
  • Sensibilidad de detección: Ajusta la precisión del sistema de headshots
⚠️ Configuración Recomendada: Para servidores de roleplay serio, se recomienda usar el modo de desmayo con efectos visuales activados para mantener el flujo narrativo.

Ejemplo de Configuración

Config = {
    unconsciousTime = 4000,  -- 4 segundos
    drunkEffect = true,      -- Activar efecto borracho
    instantDeath = false,    -- Desmayo en lugar de muerte
    headshotOnly = true      -- Solo headshots activan el efecto
}
