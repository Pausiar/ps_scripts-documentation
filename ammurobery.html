PS Ammunation Robbery

Sistema completo de robo al Ammunation para FiveM con ESX. Incluye vitrinas, estanterías, caja registradora y sistema de alertas policiales.

FiveM ESX Legacy Lua ox_target
Ver en GitHub Guía de Instalación

Showcase

Mira el sistema en acción

Características

Sistema Completo

Robo completo del Ammunation de Cypress Flats con múltiples puntos de interacción.

  • Vitrinas con armas
  • Estanterías de munición
  • Caja registradora
  • NPC informante

Sistema Policial

Verificación de policías en servicio y alertas automáticas.

  • Mínimo de policías configurable
  • Alertas automáticas
  • Integración con origen_police
  • Localización en tiempo real

Sistema de Área

Solo jugadores dentro del radio pueden participar en el robo.

  • Radio configurable
  • Detección automática
  • Blip opcional en mapa
  • Zona de seguridad

Sistema de Cooldown

Control del tiempo entre robos para mantener el balance del servidor.

  • Cooldown configurable
  • Estado persistente
  • Comando de reinicio
  • Notificaciones claras

Recompensas Variadas

Múltiples tipos de recompensas configurables.

  • Armas de las vitrinas
  • Munición de estanterías
  • Dinero negro de caja
  • Cantidades configurables

Totalmente Configurable

Todos los aspectos del script son configurables desde config.lua.

  • Textos personalizables
  • Coordenadas ajustables
  • Recompensas modificables
  • Tiempos configurables

Items Requeridos

Asegúrate de tener los siguientes items en tu base de datos:

ammo-rifle, ammo-9, ammo-shotgun, ammo-45, ammo-50, ammo-rifle2, black_money

Estos items deberían estar por defecto en ESX Legacy.

Instalación

1

Descargar el recurso

Descarga el script desde GitHub y extrae la carpeta en tu directorio de resources.

git clone https://github.com/Pausiar/ps_ammurobery.git
2

Añadir al server.cfg

Agrega la siguiente línea a tu archivo server.cfg:

ensure ps_ammurobery
3

Verificar items

Asegúrate de que todos los items necesarios estén en tu base de datos. Ejecuta la siguiente query si es necesario:

-- Los items deberían estar por defecto en ESX Legacy
-- Verifica que existan: ammo-rifle, ammo-9, ammo-shotgun, 
-- ammo-45, ammo-50, ammo-rifle2, black_money
4

Configurar el script

Edita el archivo config.lua según las necesidades de tu servidor (mínimo de policías, cooldown, etc.).

5

Reiniciar el servidor

Reinicia tu servidor o ejecuta el comando:

restart ps_ammurobery

¡Listo!

El script está instalado y listo para usar. Los jugadores pueden iniciar el robo hablando con el NPC informante.

Configuración

Todos los parámetros del script se pueden modificar en config.lua

Configuración Policial

Config.MinPolice = 1 -- Mínimo de policías requeridos
Config.PoliceJob = 'police' -- Nombre del job de policía
Config.PoliceCanRob = true -- Si la policía puede robar (para testear)

Configuración de Área

Config.RobberyRadius = 25.0 -- Radio en metros
Config.EnableBlip = true -- Activar/desactivar blip
Config.BlipSprite = 110 -- Sprite del blip
Config.BlipColor = 1 -- Color del blip

Cooldown

Config.RobberyCooldown = 60 -- Tiempo en minutos entre robos

Sistema de Progreso e Inventario

-- Opciones: 'ox_lib', 'esx_progressbar', 'custom'
Config.ProgressSystem = 'ox_lib'

-- Opciones: 'ox_inventory', 'esx'
Config.Inventory = 'ox_inventory'

Textos Personalizables

Todos los textos del script se pueden modificar en la sección Config.Texts:

Config.Texts = {
    npcDialogue = 'Tu texto personalizado...',
    notEnoughPolice = 'Mensaje personalizado...',
    robberyStarted = 'Mensaje personalizado...',
    -- ... y muchos más
}

Estanterías

Sistema de Cajas

Cada estantería tiene cajas pequeñas y grandes con diferentes tipos de munición:

  • Azul pequeña: 50x ammo-rifle
  • Verde pequeña: 50x ammo-9
  • Roja pequeña: 50x ammo-shotgun
  • Caja grande: 50x ammo-45, 50x ammo-50, 50x ammo-rifle2

Caja Registradora

Dinero Negro

Recompensa aleatoria entre $5,000 y $15,000 de dinero negro.

Mecánicas del Robo

1

Inicio del Robo

Habla con el NPC informante en las coordenadas especificadas para obtener información sobre el Ammunation.

2

Verificación Policial

El script verifica automáticamente que haya suficientes policías en servicio según la configuración.

3

Restricción de Área

Solo los jugadores dentro del radio configurado pueden interactuar con los puntos de robo.

4

Alerta Policial

Se envía automáticamente una alerta a todos los policías en servicio con la ubicación del robo.

5

Ejecución del Robo

Los jugadores pueden robar las vitrinas, estanterías y caja registradora usando ox_target.

6

Cooldown

Después de completar el robo, hay un tiempo de espera configurable antes de poder robar nuevamente.
