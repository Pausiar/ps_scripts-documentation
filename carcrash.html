🚀 Guía de Instalación

1

Descargar y Extraer

Descarga el script y colócalo en tu carpeta de recursos

# Estructura recomendada
resources/[smallResources]/ps_carcrash/
2

Añadir al Server.cfg

Asegura el recurso en tu configuración del servidor

# Añadir al server.cfg
ensure ps_carcrash
3

Configurar (Opcional)

Personaliza el comportamiento según tus preferencias

El script funciona out-of-the-box sin necesidad de configuración adicional.

4

Reiniciar y Probar

Reinicia el servidor y prueba el sistema

# Reiniciar el recurso
restart ps_carcrash

# O reinicia el servidor completo
restart
✅ ¡Instalación Completada! El sistema de colisiones estará activo inmediatamente. Simplemente conduce y experimenta los nuevos efectos realistas.

⚙️ Configuración Avanzada

Umbrales de Velocidad

Configura a qué velocidades se activan los efectos:

Config.MinSpeedForEffects = 30.0  -- km/h mínimo
Config.MediumCrashSpeed = 60.0     -- Colisión media
Config.SevereCrashSpeed = 100.0    -- Colisión severa

Intensidad de Efectos

Ajusta la intensidad de los efectos visuales:

Config.ScreenShakeIntensity = 1.0  -- 0.0 a 2.0
Config.DisorinetationTime = 5000   -- Milisegundos
Config.CameraShakeDuration = 2000  -- Milisegundos

Daño al Jugador

Personaliza el daño recibido en colisiones:

Config.EnablePlayerDamage = true
Config.MinDamage = 10              -- Daño mínimo
Config.MaxDamage = 50              -- Daño máximo
Config.DamageMultiplier = 1.0      -- Multiplicador

Efectos Visuales

Controla los efectos visuales durante colisiones:

Config.EnableScreenEffects = true
Config.EnableParticles = true
Config.EnableCameraShake = true
Config.EnableBlurEffect = true

Daño Vehicular

Ajusta cómo afecta el daño a los vehículos:

Config.EnableVehicleDamage = true
Config.DamageBodywork = true
Config.DamageEngine = true
Config.DeformationMultiplier = 1.0

Exclusiones

Define vehículos excluidos del sistema:

Config.ExcludedVehicles = {
    'ambulance',
    'firetruk',
    'police',
    -- Añade más aquí
}

🎭 Efectos Implementados

Colisión Leve

Velocidad: 30-60 km/h

  • Ligera sacudida de cámara
  • Pequeña desorientación (1-2s)
  • Daño mínimo al jugador (5-15 HP)
  • Daño cosmético al vehículo

Colisión Media

Velocidad: 60-100 km/h

  • Sacudida de cámara notable
  • Desorientación media (3-5s)
  • Daño moderado al jugador (15-30 HP)
  • Daño mecánico al vehículo

Colisión Severa

Velocidad: +100 km/h

  • Sacudida de cámara intensa
  • Desorientación severa (5-10s)
  • Daño alto al jugador (30-50 HP)
  • Daño crítico al vehículo

Efectos Adicionales

Según impacto:

  • Partículas de chispas
  • Humo del motor
  • Cristales rotos
  • Pérdida de control temporal
⚠️ Nota Importante: Los efectos son progresivos y realistas. A mayor velocidad e impacto, mayores serán las consecuencias tanto para el vehículo como para los ocupantes.

🔧 Solución de Problemas

⚠️

Los efectos no se activan

  • Verifica que el recurso esté iniciado
  • Comprueba la velocidad mínima configurada
  • Asegúrate de que no hay conflictos con otros scripts
  • Revisa la consola por errores
🎮

Efectos demasiado intensos

  • Reduce Config.ScreenShakeIntensity
  • Aumenta los umbrales de velocidad
  • Reduce Config.DamageMultiplier
  • Ajusta la duración de efectos
🚗

Conflictos con otros scripts

  • Desactiva otros scripts de daño vehicular
  • Verifica la compatibilidad de eventos
  • Ajusta el orden de inicio en server.cfg
  • Revisa logs para identificar conflictos
💡 Consejo: Si experimentas problemas, prueba con la configuración por defecto primero y luego ajusta gradualmente los parámetros.
